# Security Policy

## Versiones soportadas
Se recomienda reportar vulnerabilidades sobre la rama principal actual y las versiones publicadas oficialmente.

## Cómo reportar
- No abras issues públicos con secretos, tokens o claves.
- Si encontrás una falla de seguridad, escribí de forma privada a **pyartificial@gmail.com**. No incluyas claves API, contraseñas ni tokens en el correo.
- Incluí, si podés:
  - qué versión usás
  - pasos para reproducir
  - impacto probable
  - capturas o logs sin secretos

## Qué no publicar
- `.env`
- `granja.env`
- `cuentas.json`
- `state/`
- `state/route_rankings/`
- `state/route_health.json`
- claves API
- tokens de sesión
