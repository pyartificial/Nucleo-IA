TUS CUENTAS, EN OTRA COMPUTADORA

Trasladar cuentas

Creá un paquete en una computadora y cargalo en la otra. Las cuentas nuevas se agregan sin borrar las que ya están guardadas.

1. Crear el paquete

Descargalo en esta computadora y luego pasalo a la otra por un medio privado.

Incluye las cuentas y claves API configuradas. No incluye sesiones abiertas.

2. Cargar un paquete

Elegí el archivo creado desde la otra computadora.

Las cuentas con el mismo identificador se conservan como están. Las claves que coinciden con una clave ya configurada se omiten.

Privacidad: el paquete contiene claves API sin cifrar. Guardalo solo en un lugar privado, no lo envíes por chats o correo y borrá las copias después de cargarlo. Si podés, usá una memoria USB que tengas bajo tu control.
